# 跨入口执行与人工协作一致性

## 范围

本批基于第二批通用工具执行闭环，补齐专用服务、配置绑定和人工处理入口。不强制简单问题进入多 Agent 流程，不合并普通对话与 Agent Nexus 历史，不切换 DeepSeek 原生搜索策略。

改动前工作树快照：`frontend-backup/20260907-pre-cross-entry-consistency.zip`。本批业务提交已同步到 Gitee 与 GitHub；不包含本地配置、密钥、数据、测试截图或备份。

## 验收任务

- 专用服务：已受理请求中断、受理 ID 查询恢复、未知结果人工核对和显式重新生成。
- 结果契约：截断、空结果、部分结果、不可确认结果与缺失用量真实呈现。
- 配置绑定：两个用户和两个 Fake Provider，跨入口及重启保持归属与固定选择，不隐式回落默认云服务。
- 人工协作：计划、工具、质量、结果核对和暂停恢复均可达；陈旧页面、双击、并行审批不得绕过状态或权限。
- 前端：运行观测及 Nexus 运行测试的“需要处理”栏使用现有毛玻璃风格；保留真实信息与可操作入口。
- 发布：标准检查、专项回归、完整本地门禁、文档与版本检查、双远端提交核对。

### 验收期间修复

- 本地缺少任务绑定加密密钥：增加保留已有值的初始化工具，只在忽略的 `.env.local` 生成密钥，不打印、不提交。多 Worker 必须分发同一个值。
- 旧 PostgreSQL v3 数据库跳过新增列：独立 v4 迁移在事务与 advisory lock 内执行，增加旧库升级回归；现有业务记录未清空。
- 实时引导的旧浏览器夹具缺少新权限和工具回执字段：按新 API 契约补齐，保留真实动作断言。
- Readiness 阻断时存在未翻译系统提示：补精确及计数映射，增加两个确定性异常场景；不隐藏错误，不翻译用户内容。
- 视觉检查在真实路由返回前只等 10 秒便统计 Graph：改为仅限该单句的 route/SSE 夹具，严格验证 UI 实际请求、首次 Agent 球、完整回答持久化和历史恢复。真实模型路由、任务生命周期仍由独立门禁验证，未将无球结果放行。
- 后续整体验收中的会话测试等待多 Agent 任务超时：日志确认 Router 连接上游超时，带“最新资料”的比较输入进入单搜索兜底，测试等待的任务接口并未调用。协作历史测试改为明确要求各 Agent 独立交付，继续使用真实路由与执行；原输入的复合检索降级不足另列 TODO 的 P0 项，不以改测试前提宣称业务问题已修复。
- 明确分工后的首次专项已执行三个 Agent，但审核修正超过原 240 秒测试时限；测试取消并清理该轮任务。改用有界的 `QA_SESSION_ROUTING_TASK_TIMEOUT_MS`（默认 480 秒），记录实际耗时与末状态，不修改平台业务超时，不把慢请求记为性能通过。

此前失败日志保留在本地 `qa/cross-entry-acceptance.log`、`qa/cross-entry-release-gate.log` 等文件；最终完整通过的记录是 `qa/cross-entry-final-acceptance.log` 与 `qa/production-gate-results.json`。验收结束核对原有 19 条已完成任务和 11 个会话仍在，仅有 `127.0.0.1:8787` 提供前后端。模型连接仍有间歇波动，Readiness 会按真实探测显示阻断或降级，不能把健康端点存活等同于全部服务就绪。

## 保留边界

- 只有内联 Base64 媒体会保存为本平台 Artifact。供应商返回的外链目前按原地址展示，签名链接过期后可能无法查看；平台不会为保存外链而随意访问供应商返回的 URL。
- Artifact 写入失败后可从已保存的生成回执恢复写入，不重新请求生成；已完成任务的媒体文件后来被删除或损坏，暂未提供自助重建入口，需要存储备份恢复。
- 图片编辑沿用单张原图。视频支持当前已有标准与兼容返回结构，非标准供应商状态协议仍需适配；不宣称任何视频 API 都已现场验收。
- 两用户与两 Fake HTTP Provider 验证实际模型客户端隔离，各入口另用 API 契约验证配置传递。不是所有入口、两个浏览器同时使用真实外部供应商的端到端验收。
- 路由模型不可用时，现有兜底可能将含检索词的复合任务降为单搜索，尚不能保证与正常模型路由保持相同分工；独立协作历史验收不代表这一降级边界已解决。
