## 第一批：有效计划与成功模型响应分开

- `server/runtime/chatRouter.ts`：显式的可选 Agent/Skill ID 集合与描述性能力分离；Router 与 Scheduler 共用一次语义纠错预算，正常两次、纠错最多三次模型调用。
- 校验错误反馈仅包含结构/候选/依赖约束，不扩大权限。低置信度、网络故障不走语义纠错；取消直接退出。模型返回工具调用、截断或过大响应时，即使内容看似可解析也不接受。
- 显式空目录不替换成全量默认目录；降级不复活不可用 Agent。缺少必要能力返回 `ROUTING_CAPABILITY_UNAVAILABLE`，浏览器不再把它降级成另一个可执行方案。
- 计划仍按当前轮需要选人，新增与跳过 Agent 从真实步骤和已有 Graph 派生，不让历史 Graph 强迫全部重新执行。
- 零步骤与 Router 候选集冲突时返回可操作的约束反馈，不能默默扩充候选集。当前轮明确的“不重新/再次搜索”等全局否定约束同时作用于模型计划、旧路由与安全降级；引用和代码内容替换为占位，避免把引文当成指令或删除宾语后扩大禁令。局部对象否定、后续明确授权检索的混合语句交还 Router 判断，正常语义选人仍由 Router/Scheduler 模型完成。
- `/api/chat/route` 返回 `diagnostics.calls/events/summary`，区分请求完成、校验通过、纠错、降级，并单独统计修正开销。未知用量仍为 `null`。
- 该 HTTP 入口整体 45 秒预算，浏览器 50 秒等待边界。未知网络结果不自动重新发起整次调度；明确的可重试 HTTP 错误仍有一次受限重试。此预算不修改一般任务执行时限。

## 第二批：有边界的基线/候选对照

入口：左侧“任务改进”→ 已生成建议 →“先对照，再决定”。使用同一来源任务模型，对五类固定合成文本样例分别加入和不加入建议。HTTP 202 返回持久评测记录，随后查看进度；不阻塞到最终答案才反馈。

- 五类样例分别针对给定资料报告、文档摘录、插件修改要求、Nexus 分支/Loop 文本规则、多轮要求变更。
- 代码检查事实、要求、引用和严格结构，不使用模型自评。任一配对检查退化优先于总分提高；失败或不完整为证据不足。
- 记录每组原文、检查依据、耗时、Token、尝试次数与评测版本摘要；没有金额定价和人工干预观测，不伪造这两项。
- 评测调用单独限制 `maxAttempts: 1`，避免底层重试突破十次调用的预算；请求级限制只能减少、不能扩大客户端已配置的尝试次数，普通任务重试不受影响。
- SQLite `BEGIN IMMEDIATE` 与 PostgreSQL 提案行锁防止跨页面/跨 Worker 重复领取；幂等键重放不再次付费，同提案已有运行时拒绝其他新请求。
- 源任务、谱系、所有者、提案版本、评测 revision 与租约联合检查；取消、超时、来源变化后迟到响应不能覆盖终态。过期运行保留部分结果，不自动重放付费调用。
- 历史先按提案过滤再分页上限，不被无关提案记录挤掉。前端采用现有主题和毛玻璃样式，中英文切换不修改模型原文。

## 明确没有声称完成的内容

这不是原任务 Graph 的 A/B 重放，不实际执行搜索、PDF/OCR、插件、Nexus 引擎或外部工具。只有固定文本契约和模拟场景。样例独立于原任务和复盘建议的测试题，但公开且会重复使用，不是永久盲测；直接标记重叠检测也不是完整反污染方案。

“样例中有改善”只描述本次精确检查，不证明广泛业务质量或统计显著性。建议全局状态仍是未验证，不自动发布策略、训练模型、改权限或写入长期记忆。用户仍通过可编辑新对话草稿决定试用。

### 保留的首轮问题，不用重试覆盖

第一轮完整门禁汇总为 43 passed / 0 failed / 3 skipped，但在线路由阶段实际上第一次 6/7，门禁自动重试才 7/7。失败场景是用户要求“不要重新搜索，仅把上一轮结论整理成三个要点，不要新增事实”：Scheduler 生成的直达计划不在 Router 候选集内，一次修正后仍被拒绝；旧降级检索词匹配随后把“不要重新搜索”误判为搜索。

两次在线原始观察分别保留在 `qa/routing-eval-2026-09-20T07-54-55-948Z-results.json` 与 `qa/routing-eval-2026-09-20T07-55-16-415Z-results.json`，门禁汇总保留在 `qa/routing-rsi-first-gate-results.json`。此后在线路由门禁不再自动重试整套样例，改用 `QA_ROUTING_REPEATS` 明确重复观测，任一次失败都使该阶段失败。

独立只读复查另发现局部否定被扩大为全局禁搜的问题：“不用搜索天气，只查询今天的美元人民币汇率”。已将硬约束收窄为完整、无具体对象的全局禁止子句，并保留引用占位和后续明确授权的语义边界；中英文模型路由、安全后处理及浏览器降级回归均覆盖。该修复后 Router/浏览器专项 61/61、故障评测 224/224、隔离 HTTP/SSE 11/11；最终全量门禁重新启动后才作为交付版本验收。

真实 RSI 冒烟使用 `deepseek-chat` 和固定中性检查建议：十次请求全部完成，共 3,126 个已报告 Token；未加入建议组 30/30，加入建议组 29/30。差异是文档预算题候选回答 5,200，而给定变更后的正确结果为 4,700。系统正确标记 `regressed`，没有自动采用，也没有重试刷成“提升”。这证明对照机制能够记录本次退化，不证明一般业务效果。原始结果为 `qa/improvement-live-eval-2026-09-20T07-52-08-546Z-results.json`。
