# 对话预览滚动闪烁修复

日期：2026-09-09。基于 v2.3.0-rc.7。

## 原因与复现

`src/components/dashboard/ChatArtifact.tsx` 在每次渲染时重新创建 ReactMarkdown 的 `components` 回调。React 将这些回调视为新的组件类型，导致父组件更新时卸载并重新创建 HTML/SVG iframe、文件预览和媒体元素。向上滚动触发“回到最新消息”按钮显示，就足以重置预览；输入文字及后续流式消息也能触发同一问题。

修改前在真实 DashboardChat 页面复现：一次向上滚动重建了 5/5 个受测预览元素；HTML 初始化次数从 1 增至 2，文件、图片与视频再次请求，视频音量从 0.37 重置为 1。

## 修复后的行为

- Markdown 渲染组件保持稳定身份，配合 memo 保留已有预览。滚动、输入、同会话新增消息、主题切换和后续流式文字不再重建内容未变化的预览。
- HTML/SVG 围栏代码生成过程中先显示“正在生成作品…”，有效结束围栏到达后再加载。后续说明文字继续输出时保留已加载的作品；裸 HTML/SVG 等待消息完成再呈现，避免不断执行半成品。
- 围栏判断结合 Markdown 解析器的实际源码范围和解析内容，覆盖反引号、波浪线、引用块、嵌套列表、CRLF 和伪结束围栏。
- 普通对话和 Agent Nexus 共用修复后的渲染器，并将会话/流程标识纳入消息身份。保留同一会话中的预览状态，切换到其他会话时重新初始化，避免相同消息 ID 串用交互状态。
- 源文件真正变化时仍更新预览。原有复制、下载、失败重试、鉴权及 iframe 隔离限制保持有效。

也检查了插件窗口、插件工作台和页面翻译逻辑，未发现相同的预览卸载重建原因，未对这些区域做无依据的改动。
