# 独立成果生成与聊天确认修复

日期：2026-09-08。基于 v2.3.0-rc.7，未改变现有模型和数据库配置。

## 问题

创建 SVG、HTML 动画等独立成果时，模型选择了 `workspace.write`。该工具可覆盖项目文件，因此固定要求人工批准。审批在完整工具参数生成后才产生；聊天操作面板又依赖任务列表的延迟刷新，造成等待和跨页面操作。

## 修复后的行为

- 新增 `artifact.create`，接受文件名和完整内容，支持 HTML、SVG、Markdown、TXT。文件保存到当前租户与任务的成果存储，无需额外审批，不写入项目工作区。
- 规划、执行和直接对话提示根据任务范围交付成果。没有成果存储或工具权限时，可直接返回可预览、复制、下载的完整代码块。
- 实际生成文件的标识随工具执行回执持久化。重放复用同一个文件，可补齐目录登记，不重复写入，不恢复已删除或过期成果。
- 最终汇总遗漏交付链接时，运行时依据真实工具回执补齐。质量审查可受控读取源文件，按用户请求审查，不为普通绘图凭空增加部署或项目测试要求。
- 生成文件经任务所有者/管理员和租户校验后以下载附件传输。HTML/SVG 在隔离 iframe 中预览，支持复制、下载和加载失败重试。
- 审批 SSE 事件直接驱动当前聊天操作面板，停止陈旧的思考状态；普通工具“允许此次”或“拒绝调用”单击即可完成决定，critical 操作仍保留最后确认。
- 工作区文件修改等原有高风险操作继续保留权限、审批、任务版本及并发校验。
- 一并修复 PostgreSQL 审批对象数组的 JSONB 参数序列化，覆盖待审批、批准、清空和 null 状态。
